# Build your first family map

Open **Getting started** using the book button beside the language selector. It is available on the home screen and throughout the workspace in EN / UA / RU. The guide includes a downloadable practice JSON with the same people, relationships and groups described below.

## 1. Create a map

On the home screen, enter a title, select **Family and genealogy**, then **Create map**. Begin with one branch and extend it as information becomes available. Workspace modes suggest tools and visible sections; changing a mode preserves the recorded data.

From an open map, choose **New tree** at the bottom of the sidebar to return to the home screen. On a phone, open the navigation menu first. Export the current project before creating another one.

To inspect the finished exercise first, download **Example JSON** from the in-app guide, close the guide and use **Import**. Export your current project before importing another one. Downloading the example itself does not change the current map.

## 2. Add people once

Choose **Add person** on the map or in **People & profiles**. Enter a name and save. Add dates or years, gender and life status when known. Only the name is required.

To connect the person immediately, enable **Add relationships now** in the basic information section. Choose an **Existing person** and the **New person is their…** role. For example, select Alex Doe and **Child** when adding Jamie Doe. Use **Add another relationship** to add Morgan Doe as the second parent. The person and every entered relationship save together and can be undone with one action. Leave this option unchecked to create a person without relationships.

New cards appear near the current map view or their linked relatives, avoiding existing person cards. The map centers the new person without fitting the entire tree. On phones and tablets, the overlapping person panel closes so the new card remains visible; select the card to reopen it.

For this exercise, enter these eight fictional people. The dates supplied are birth years, not complete birth dates.

| Current name | Gender | Birth year | Maiden surname |
| ------------ | ------ | ---------- | -------------- |
| Alex Doe     | Male   | 1960       |                |
| Morgan Doe   | Female | 1962       | Roe            |
| Jamie Doe    | Male   | 1985       |                |
| Casey Doe    | Female | 1987       | Hart           |
| Taylor Lane  | Female | 1988       | Doe            |
| Jordan Lane  | Male   | 1986       |                |
| Robin Doe    | Male   | 2010       |                |
| Avery Lane   | Female | 2012       |                |

Use the current name in the main field. Add maiden surnames and previous names in **Names and surnames**, including dates and sources if available. Keep one profile per person, including after marriage, adoption or a name change.

## 3. Record relationships

Choose **Add relationship**, select **First person**, **Second person** and the relationship type, then save. Add dates, status and supporting sources when known.

For faster entry, select exactly two cards with **Ctrl / ⌘ or Shift + click**, in the required order, then choose **Add relationship** on the selection strip or the map toolbar. Both people are filled in automatically. You can also click the first person normally, then Ctrl / ⌘ + click the second. Modified clicks work in the sidebar people list too. Review the relationship type and direction before saving. An explicit relationship action from a person's profile takes precedence over the map selection.

Create these three **Registered marriage** relationships. Each marriage needs one entry; either partner may be selected first.

| First person | Second person |
| ------------ | ------------- |
| Alex Doe     | Morgan Doe    |
| Jamie Doe    | Casey Doe     |
| Taylor Lane  | Jordan Lane   |

For **Biological parenthood**, the **first person is the parent** and the **second person is the child**. Create a separate entry for each known parent of each child:

| First person: parent | Second person: child |
| -------------------- | -------------------- |
| Alex Doe             | Jamie Doe            |
| Morgan Doe           | Jamie Doe            |
| Alex Doe             | Taylor Lane          |
| Morgan Doe           | Taylor Lane          |
| Jamie Doe            | Robin Doe            |
| Casey Doe            | Robin Doe            |
| Taylor Lane          | Avery Lane           |
| Jordan Lane          | Avery Lane           |

The result is eight people and eleven relationships across three generations. Jamie and Taylor are siblings because they share Alex and Morgan as parents. Robin and Avery are first cousins through those same grandparents. Grandparents, siblings, aunts, uncles and cousin degrees are calculated from family links; shared surnames or group membership do not establish ancestry. For more distant cousins, extend both branches back to their common ancestors.

Use **Adoption** for an adoptive parent and retain separate biological links when known. **Step-parenthood** is another relationship type. Dating and cohabitation belong under **Partnership / dating**, with their kind, period and status. Keep separate episodes when a relationship ends and later resumes. Use **Possible kinship** and verification details for uncertain information.

## 4. Organize families into groups

Use the add button beside **Family groups**. Enter a name, choose a color, check the members and save. Create these groups:

| Group                | Members                     |
| -------------------- | --------------------------- |
| Alex & Morgan Doe    | Alex, Morgan, Jamie, Taylor |
| Jamie & Casey Doe    | Jamie, Casey, Robin         |
| Taylor & Jordan Lane | Taylor, Jordan, Avery       |

Jamie and Taylor each belong to their parents' group and their own household. Use the same profiles in both groups. Groups can also represent a family branch or a research collection; they organize the workspace and do not create marriages or parenthood.

Select a group to focus the map and lists. **Whole family** returns to all people. Edit a group to change its members or collapse and expand it on the map.

## 5. Complete profiles gradually

Open a person in **People & profiles** and choose **Edit profile**. Find a section using the contents, section search or the section picker on a phone. Add individual records and expand optional details as needed.

- **Education:** institution, school or university, qualification, specialty and attendance or graduation dates.
- **Residence and travel:** countries, places and periods of residence or visits.
- **Identity documents:** document type, series, number, issuer, issue and expiry dates.
- **Hobbies and skills:** interests and abilities, with periods and qualifications where useful.
- **Habits and beliefs:** routines, preferences and views, with their periods and attribution.
- **Health:** general notes, conditions, allergies, treatment and medical dietary restrictions.

Other sections cover work, civil records, property, finances, legal events and additional information. **Choose visible data** controls the compact panel; complete profiles and autobiographies still include all entered sections. Use a person's star to keep them close at hand while working.

## 6. Link documents and sources

Open **Documents** and add a file, or choose **Record without a file** for a source that has not been digitized. Enter its title, type, date, archive or reference details and provenance. Link the relevant people and relationships. A linked source becomes accessible from their profiles.

For example, link a birth certificate reference to Robin, Jamie and Casey and to Robin's two parenthood relationships. The parenthood entries must still be created separately. Passport details go in the profile's **Identity documents**; the scan can be stored as a linked source.

For a statement, recording or rumor, record who supplied it, when and what requires checking. Document availability and verification are separate. Uploading a file does not automatically confirm its contents. Civil records likewise do not automatically change names or family links.

## 7. Arrange and explore the map

Select **Generations** under **Layout**, then **Show entire tree**. Reapply the layout as the tree grows and drag individual cards when needed. Select a person to see their relatives' roles. **How are we related?** compares two people; **Connection search** finds paths and networks. The top search and filters find recorded values and combinations.

On a phone, pan with one finger and zoom with two. Enable **Move cards** to drag person cards. **Map options** opens layout, display and analysis controls.

On tablets, **Map options** also keeps these controls together and leaves more space for the tree. Touch the selection-mode button there to select several people without a keyboard.

If a person appears to be missing, check the active group, collapsed groups, search or analysis results, and **Display** settings. These controls hide data from the current view without deleting it.

## 8. Back up and print

Choose **Export tree → Full ZIP archive for editing** for an editable backup including attachments. Restore it through **Import**. JSON contains project data without attachment files. PNG and SVG are map images and cannot restore an editable project.

Open a person's **Autobiography**, then **Print / Save as PDF**. Choose a printer or Save as PDF in the browser's print dialog.

Autosave stores a draft in this browser on this device. Export ZIP regularly and before opening another project; drafts do not synchronize between browsers or devices.
